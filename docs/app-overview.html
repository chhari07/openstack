WEB VS APP

Both versions are built from the same Next.js code. The web app runs with a server; the Android app is a self-contained APK (Capacitor) with native features. In short: the web app is a reader you open in a browser; the APK adds everything that uses the phone itself: music, files, notifications and background playback.

NEXT UPDATES

Four phases, ordered so that each one builds on the last. Phase 2 holds the features that no competitor combines.

PHASE 1 · FINISH & STABILISE

Week 1
  • Spotify inside Stack with the App Remote SDK, so "no active device" never appears (code parked in native/wip/)
  • Release-signed APK with version numbers and an in-app "update available" check
  • Offline cache: today's cards and saved articles readable without network
  • Deploy the web app (Vercel) for a shareable link

PHASE 2 · STACK'S UNIQUE FEATURES

Weeks 2–3
  • Focus session: pick a PDF or article → 25-min timer + music + notes → summary at the end
  • Share to Stack: send links from Chrome, YouTube or WhatsApp straight into the Library
  • Listen mode: articles and PDFs read aloud, with controls in the media notification

PHASE 3 · SMARTER READING

Weeks 4–5
  • 60-word AI summaries on news cards and "explain this" on selected text (Gemini free tier)
  • Personal feed: choose topics on first launch; Hindi news sources
  • Breaking-news alerts per topic (background fetch with WorkManager)

PHASE 4 · YOUR DATA & REACH

Week 6+
  • Export notes to Markdown; Google Drive backup or optional cloud sync
  • Resurface an old highlight in the daily digest (spaced review)
  • EPUB books, reading stats and streaks
  • Play Store build: folder picker + music-only permission instead of All files access
